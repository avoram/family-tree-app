# Photos — Vora Family

Add member photos here and link them in `family-trees/vora.tree.json` via `photoUrl`.

Example already linked:

| Member | File | JSON `photoUrl` |
|--------|------|-----------------|
| Mayank Vora | `mayank.jpg` | `photos/vora/mayank.jpg` |

For any other member, use the same pattern:

```text
photos/vora/<memberId>.jpg
```

and set that path on the member's `photoUrl` field in the JSON.
